## 🎨 Customize

### Change Brand Name
- Find: `VELM<span>ORA</span>`
- Replace in: All HTML files

### Change Primary Color
- Edit in `styles.css`:
  ```css
  --bg-primary: #070707;
  --text-primary: #fff;
  --accent: #fff;
  ```

### Add New Products
- Edit `products` array in `script.js`
- Each product needs: `id`, `name`, `category`, `price`, `rating`, `reviews`, `image`

### Customize Footer
- Edit footer links in `index.html`, `shop.html`, category pages
- Footer is consistent across all pages

## 🆘 Troubleshooting

### Products Not Showing
- Check browser console for errors (F12)
- Ensure script.js is loaded
- Verify products array in script.js

### Cart Not Saving
- Check if localStorage is enabled
- Clear browser cache
- Try incognito mode

### Links Not Working
- Verify file names match exactly
- Check file paths (no extra folders)
- Ensure .html extensions are correct

### Styling Issues
- Clear browser cache (Ctrl+F5)
- Check styles.css is loading
- Verify CSS file is in root directory
